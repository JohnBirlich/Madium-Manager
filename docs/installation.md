# Установка, обновление и удаление

## Рекомендуемый способ: MSI

MSI устанавливает Madium Manager для текущего пользователя и регистрирует приложение в Windows. Права администратора для штатной per-user установки обычно не требуются.

### Обновление

1. Закройте Madium Manager и завершите активные демо/production-сессии.
2. Запустите новый `MadiumManager-<version>-win-x64.msi`.
3. Windows Installer использует общий `UpgradeCode` и возрастающий номер версии. `MajorUpgrade` удаляет предыдущую установку на стадии `afterInstallValidate`, поэтому две версии программы не остаются side-by-side.
4. Понижение версии блокируется сообщением установщика.

Аккаунты и настройки при обновлении сохраняются намеренно. Они находятся в `%LocalAppData%\MadiumManager`, отдельно от удаляемых program files.

### Удаление

Доступны два стандартных способа:

- **Windows → Параметры → Приложения → Установленные приложения → Madium Manager → Удалить**.
- **Пуск → Madium Manager → Удалить Madium Manager**. Этот пункт вызывает `msiexec /x` с `ProductCode` установленной версии.

Удаляются исполняемый файл, ярлыки и регистрация приложения. Пользовательские `accounts.json` и `settings.json` не удаляются автоматически, чтобы не потерять данные. Если нужно полное удаление, сначала сделайте backup, затем после деинсталляции удалите `%LocalAppData%\MadiumManager` вручную.

## Portable ZIP

ZIP не имеет собственного uninstaller и не может заменить запущенный exe автоматически:

1. Закройте приложение.
2. Удалите старую распакованную папку или распакуйте новую версию поверх после завершения процессов.
3. Не запускайте одновременно exe из старой и новой папок.

Для автоматического замещения старой установки и удаления через Windows используйте MSI.

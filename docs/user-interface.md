# Интерфейс Madium Manager

## Разделы

- **Обзор** — счётчики аккаунтов и сессий, live-список запущенных сессий, uptime, быстрые действия и последние события.
- **Аккаунты** — добавление/изменение/удаление, поиск, server-side статус, Medium state, последний сервер, последняя проверка и действия по строке.
- **Журнал событий** — поиск, фильтр по уровню, очистка и экспорт последних 400 событий в UTF-8 text.
- **Настройки** — Medium path, working directory, startup timeout, restart limit и server-side check перед запуском.

## Интерактивные сценарии

В версии интерфейса без реального Medium-контракта используется `DemoAccountRuntimeService`. В окне постоянно отображается **ДЕМО-RUNTIME**, а сервис не вызывает `Process.Start` и не создаёт процессы ОС.

1. Нажмите **«Запустить следующий»** или **▶** у аккаунта.
2. Дождитесь переходов `Проверка → Запуск Medium → Работает`.
3. Нажмите **↻**, чтобы смоделировать падение. Интерфейс покажет `Reconnect` и восстановит сессию на том же сохранённом IP.
4. Нажмите **■**, чтобы остановить сессию.
5. **✓** выполняет демонстрационную server-side проверку.

Специальные логины:

- `demo.north`, `demo.beta` — обычный успешный сценарий;
- значение с `ban` — демонстрационный статус `Banned`;
- значение с `timeout` — демонстрационный startup timeout и пропуск аккаунта.

`MaxAutomaticRestarts` ограничивает демонстрационные reconnect, а настройка startup timeout отображается в timeout-сценарии.

## Данные

При первом запуске создаются три явно названных demo-аккаунта. Метаданные аккаунтов и настройки атомарно сохраняются в:

```text
%LocalAppData%\MadiumManager\accounts.json
%LocalAppData%\MadiumManager\settings.json
```

Форма аккаунта не запрашивает пароли, токены или cookies. Кнопка **«Восстановить демо-аккаунты»** доступна после остановки всех сессий.

## Граница реальной интеграции

`IAccountRuntimeService` отделяет ViewModels от runtime. Для production необходимо заменить demo-сервис адаптером, который использует `MediumInjectorBridge`, реальный `IMediumReadinessProbe` и `IAccountStatusChecker`. Пользовательский интерфейс при этом сохраняется, а demo-badge должен быть удалён вместе с demo-runtime.
